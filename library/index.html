Mini Library System

A small project for organising books, tracking copies, and practising object-oriented programming.

Created by Mohan Mittapally

What the Python project does

The Mini Library System uses Book and Library classes to keep book information organised. It can add books, merge copies when a title already exists, lend and return books, and stop a book's available-copy count from going below zero.

The Python version practises JSON save/load, CSV export, reading text files, and exception handling. This webpage is a small browser demonstration; its sample data stays in the page and is not saved to the Python files.

Python concepts practised

  • Classes and objects: represent books and the library.
  • Encapsulation: keep the copy count protected inside the Book object.
  • Conditions and loops: find titles and check book availability.
  • File handling: save or load JSON data and export CSV.
  • Exception handling: deal with invalid input or file errors.
Built with HTML, CSS and JavaScript. The original project is written in Python.
